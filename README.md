# JAWS 日本語じょうず

英語などでの表記は「JAWS: Nihongo Jozu」。リポジトリ名は `akapen`（赤ペン。先生の添削）のまま。

日本で暮らす外国人が、生活の電話（粗大ごみの申し込み、お店やタクシーの予約、病院の予約など）を、**本番の前に声で予行演習**する Web アプリです。

> Built with Claude: Japan 2026 に向けて作っています。仕様は [docs/spec.md](docs/spec.md)、計画は [docs/plan.md](docs/plan.md)。

1. **場面を選ぶ**: 文化庁の「生活Can do」一覧から、電話や窓口でのやり取りの場面を選びます（手書き4 ＋ Claude が下書きし、別の検査役を通した46。一覧は [docs/scenes.md](docs/scenes.md)）。
2. **予行演習**: Claude が相手役（受付・店員など）になり、声でやり取りします。相手役は本物の受付のように話し、日本語を教えたり直したりしません。
3. **赤ペン**: 会話の記録に、日本語教師の赤ペンのように赤を入れます。文法の正しさより「**伝わったか**」を先に見ます。本番までに直すのは多くても3つ。言いよどみ（えっと・あの）は直しません。
4. **本番のカンペ**: 本番の電話で手元に置くメモを作ります。聞かれること・言うこと・困ったときの言い方を、その人の言語と並べ、その場面で前もって知っておくこと（生活・文化・社会的情報）を添えます。QR でスマホに送ると、大きい文字の本番用の画面で開きます。
5. **もう一度練習**: 赤ペンの「次はどう言う？」を横に置いて同じ場面を練習し、2回目の赤ペンで前回のつまずきが直せたかを見ます。

学習用の会話相手ではなく、**本番を通すための予行演習とカンペ**です。

画面の言葉と場面の名前は、日本語のほか、やさしい日本語・英語・中国語・ベトナム語・フィリピン語・ネパール語・インドネシア語・ポルトガル語・韓国語・ミャンマー語で読めます（右上で選ぶ）。訳は、まず出入国在留管理庁・文化庁のガイドラインに沿って **やさしい日本語** に書き換え、それを元に各言語に訳しています（`scripts/build-i18n.ts`）。会話そのものは日本語のままです。赤ペンの説明は、選んだ言語を添えます。

## しくみ

| 役         | 使うもの                                                                                          |
| ---------- | ------------------------------------------------------------------------------------------------- |
| 文字起こし | ElevenLabs Scribe（`no_verbatim: false`。学習者の誤りや言いよどみを、正しい日本語に直さずに残す） |
| 相手役     | Claude API（場面カードに沿って、本物の受付として話す）                                            |
| 赤ペン     | Claude API（相手役とは別の呼び出し。生活Can do と日本語教師の優先順に照らして見る）               |
| カンペ     | Claude API（渡された「知っておくこと」だけを元に書き、料金や制度などの事実を足さない）            |
| 相手役の声 | ElevenLabs の読み上げ（声を設定したとき）か、ブラウザの読み上げ                                   |

赤ペンの優先順: 用件が変わる・止まる ＞ 相手の言葉を聞き取れていない ＞ 失礼に聞こえそう ＞ 文法・語の誤り。

### 評価

作り手（日本語教師）が入れた赤ペンと、Claude の赤ペンがどれだけ合うかを測ります（`eval/`）。会話はすべて架空です。

```bash
vpx scripts/eval.ts --runs 2      # ANTHROPIC_API_KEY が必要
vpx scripts/gold-sheet.ts > docs/eval-gold.md   # 正解の赤ペンを読みやすい形に
```

## 守ること

- 医療の助言はしません。病院の場面でも、相手役は受付として名前・日時・用件を聞くだけです。
- 110番・119番など、安全や生命にかかわる場面は予行演習にしません。多言語の窓口を案内します。
- 「生活Can do」は「できるようにならなければならない一覧」ではありません。
- 会話の相手・店・地名・電話番号はすべて架空です。実在の人の録音・文字起こしはリポジトリに入れません。

## 使い方（ローカル）

必要なもの: Node.js 22 以上、[Vite+](https://viteplus.dev/)（`npm i -g vite-plus`）

```bash
vp install
cp .dev.vars.example .dev.vars   # ANTHROPIC_API_KEY と ELEVENLABS_API_KEY を入れる
vp dev                           # root で動くコンテナでは CI=1 vp dev
```

キーが無くても、「見本の赤ペンを見る」で手で作った見本を見られます。

確認: `vp check`、`vp exec vue-tsc -b`、`vp test`

## 出典

- 文化審議会国語分科会「地域における日本語教育の在り方について」（報告）別冊「日本語教育の参照枠」に基づく「生活Can do」一覧（令和4年11月29日、文化庁 https://www.bunka.go.jp/seisaku/bunkashingikai/kokugo/hokoku/ ）を加工して作成。公共データ利用規約（PDL1.0）。取り込みは [yasashii-refs](https://github.com/silloi/yasashii-refs) の `data/seikatsu-cando.jsonl` から（`scripts/build-data.ts`、出典の詳細は `data/cando.meta.json`）。
- 出入国在留管理庁・文化庁「在留支援のためのやさしい日本語ガイドライン 別冊 やさしい日本語書き換え例」（2020年8月 https://www.moj.go.jp/isa/support/portal/plainjapanese_guideline.html ）を加工して作成（PDL1.0）。画面の言葉をやさしい日本語に書き換えるときの用語集（`data/plain-japanese.json`、出典の詳細は `data/plain-japanese.meta.json`）。
