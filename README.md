# JAWS 日本語じょうず

生活の電話や窓口のやり取りを、**本番の前に声で予行演習**する Web アプリです。伝わらなかった所に日本語教師の赤ペンを入れ、本番で手元に置くカンペを作ります。

- 公開先: https://jaws.ni-hongo.workers.dev （ログイン不要。スマホでも PC でも）
- デモ動画: 準備中（11/8 に追加）
- Built with Claude: Japan 2026 の作品です。作り手は日本語教師です。

アプリの名前は「JAWS」で、副題は言語ごとに訳し分けています（英語 JAWS: Good for Japanese、中国語（简体）JAWS 日语说得很好、中国語（正體）JAWS 日語說得很好、韓国語 JAWS 일본어 잘하다 など）。リポジトリ名の `akapen` は「赤ペン（先生の添削）」です。

## 誰のための、何か

日本語が初級〜中級の、日本で暮らす外国人のためのものです。粗大ごみの申し込み、お店・タクシー・病院の予約、役所の窓口での手続き。電話は顔が見えず、聞き返しにくく、本番は一度きりです。実際に、病院の予約の電話をかける前に、生成 AI を相手に練習していた人がいました。けれど、ふつうの AI の会話相手は、分かりにくい答えでも都合よく汲み取って先に進み、本番の相手がどこで困るかを教えてくれません。

JAWS は、学習用の会話相手ではありません。**本番を通すための予行演習とカンペ**です。

1. **場面を選ぶ**: 文化庁の「生活Can do」から作った50場面（電話22・窓口28）。練習の画面には、本番で聞かれることが、聞かれる順に、練習用の架空の答えと並んで出ます。
2. **予行演習**: Claude が本物の受付として話します。日本語を教えず、直さず、あいまいな答えには本物のように聞き返します。本番で起きやすいこと（例: 冷蔵庫は粗大ごみで出せない）が1つ入ります。相手の様子（ていねい・ふつう・急いでいる・気むずかしい）は、開始のたびに変わります。相手が話し終えると、そのまま聞き取りに入ります。会話の文にはふりがなが付き、文をタップすると、選んだ言語で意味が出ます（日本語の画面では、やさしい日本語に言い換えます）。相手の言葉の中の、手続き・書類の語や電話の言い回し（転入届・処理券・折り返し・少々お待ちください など）には点線の下線が付き、タップすると、その語の訳と、やさしい日本語の説明が出ます。
3. **赤ペン**: 会話の記録に、日本語教師の赤ペンのように赤を入れます。文法の正しさより「**伝わったか**」を先に見ます。本番までに直すのは多くても3つ。言いよどみ（えっと・あの）は直しません。伝わった所には ○ を付けます。会話に出てきたことばの意味も、一覧で見られます。
4. **本番のカンペ**: 聞かれること・言うこと・困ったときの言い方を、その人の言語と並べます。赤ペンで直した言い方が入り、その場面で前もって知っておくことと、ことばの意味を添えます。QR でスマホに送ると、大きい文字の本番用の画面で開きます。カンペの画面の下には、**その場面に関係する公的な情報**（国などのページ。住所の届け出・部屋探し・年金・学校の手続き など）と、外国人のための相談窓口の一覧へのリンクを出します。カンペを作っている間から見えます。
5. **もう一度練習**: 赤ペンの「次はどう言う？」を横に置いて同じ場面を練習し、前回のつまずきが直せたかを ○△ で見ます。

画面は、日本語・やさしい日本語・英語・中国語（简体）・中国語（正體。台湾の繁体字）・ベトナム語・フィリピン語・ネパール語・インドネシア語・ポルトガル語・韓国語・ミャンマー語で読めます。中国語は字だけでなく語彙も分け、正體は台湾でふつうに使う言い方で訳しています（台湾出身の人に、簡体字しかないと言われたので足しました）。会話そのものは日本語のままです。

## 試し方

1. https://jaws.ni-hongo.workers.dev を開き、右上で言語を選びます。
2. 場面を選びます。はじめてなら「粗大ごみの回収を電話で頼む」がおすすめです。
3. 「話す」を押して日本語で話し、話し終わったらもう一度押します。マイクが使えないときは「キーボード」で入力できます。名前・住所・電話番号は、画面に出る架空のものを使えます。
4. 電話が終わったら「赤ペンを見る」、次に「本番のカンペを作る」、最後に「スマホで開く（QR）」です。

結果だけ先に見るなら、場面の一覧の「見本の赤ペンを見る」を押します。手で作った見本で、Claude を呼びません。

## Claude の使い方

| 役     | 何をするか                                                                                                                                                                                                                                                    |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 相手役 | 場面カード（聞くこと・本番で起きやすいこと・してはいけないこと）と、今日の日付とカレンダーを渡し、本物の受付として話させる。通じないときは段階を踏んで聞き返す。役所の場面だけ、自治体の電話応対にならって、やさしい日本語に切り替えてよい。                  |
| 赤ペン | 相手役とは**別の呼び出し**。演じる役と、指針に照らして見る役を分ける。優先順は「用件が変わる・止まる ＞ 聞き取れていない ＞ 失礼に聞こえそう ＞ 文法」。2回目以降は、前回の赤ペンを渡して ○△ を返させる。                                                     |
| カンペ | 渡した「知っておくこと」（場面のメモと、生活・文化・社会的情報）**だけ**を元に書かせ、料金や制度などの事実を足させない。                                                                                                                                      |
| 場面   | Claude が生活Can do から場面カードを下書きし、**別の呼び出しの検査役**が決まった項目（実在の名前・電話番号、医療の助言、Can do との対応など）で確かめ、通らなければ1回だけ書き直させる。先生が確かめるまで「下書き」として扱う（`scripts/build-scenes.ts`）。 |
| 多言語 | 画面の言葉を、まずガイドラインに沿って**やさしい日本語**に書き換え、それを元に10言語に訳す（`scripts/build-i18n.ts`。中国語は简体と正體の2つ）。                                                                                                              |

- モデルは `claude-opus-5-5`。赤ペン・カンペ・相手役の返事は構造化出力（`output_config.format`）で受け取ります。混んでいるときは別のモデルに切り替わる設定です（`fallbacks: "default"`）。
- Claude の出力をそのまま信じない: 赤ペンの引用が会話に文字どおりあるかを照合し、無いものは捨てます。優先順の並べ替えと「多くても3つ」はコードで決めます（`shared/validate.ts`）。
- 相手役が会話を終えた瞬間に、裏で赤ペンを始めます。「赤ペンを見る」を押したときには、たいてい出来ています。

### 評価（先生の赤ペンと比べる）

架空の会話8本に、正解の赤ペン（日本語教師の判断）を用意し、Claude の赤ペンがどれだけ合うかを測ります（`eval/`、各2回）。指示（`shared/prompts.ts`）を変えるたびに版を上げて測り、結果を [docs/eval.md](docs/eval.md) に残しています。

| 指示の版     | effort | 拾えた | 合っていた | 種類が合う | 1番が合う | 直さなくていい所への赤 |
| ------------ | ------ | ------ | ---------- | ---------- | --------- | ---------------------- |
| 2026-11-06.1 | high   | 67%    | 44%        | 92%        | 50%       | 0                      |
| 2026-11-06.2 | high   | 61%    | 79%        | 73%        | 75%       | 0                      |
| 2026-11-08.1 | medium | 67%    | 86%        | 92%        | 81%       | 0                      |

- 最初の版は、学習者が**言わなかったこと**（「電話番号をまだ言っていません」）にも赤を入れ、合っていた割合が 44% でした。「赤は実際に言ったことにだけ」などと指示を直すと 79% になりました。アプリは速さのために effort を medium にしています。
- 正解は、Claude Code が下書きし、日本語教師の作り手が8本すべてを確かめました（最後の行は、その正解で測った結果）。確かめるための道具も作りました: https://jaws.ni-hongo.workers.dev/dev/gold 。会話ごとに赤と「直さない」所を入れ直し、最新の評価で Claude が入れた赤と並べて、食い違いを見ます。先生の判断と、その理由がデータとして残ります。
- 先生と Claude の判断が食い違ったのは、ほぼ1つの所です。学習者が分からない語に「はい」とだけ答えた所で、先生は「保険証・処理券のように用件に欠かせない語なら、はいだけでも赤」、Claude は「分かっていなかった証拠が会話に無ければ入れない」としました。拾えなかった赤は、すべてこれです。先生が「直さない」とした所に、Claude が赤を入れたことはありません。
- 相手役も確かめています。学習者が「来週の火曜日は、いいですか？」と言ったとき、日付を知らない相手役は日付を一度も言えませんでした（16回中0回）。今日の日付とカレンダーを渡すと、16回とも正しい月日と曜日で確かめました（`scripts/check-dates.ts`）。

## Claude Code の使い方

- **セッションの分担**: 企画のセッションが、別の環境に開発のセッションを立ち上げて、方針を渡しました。開発のセッションは、`CLAUDE.md` に書いた約束（医療の助言をしない、場面は架空、指示を変えたら評価する など）を守りながら、作り手と日本語で短くやり取りして作りました。提出準備のセッションは、試し撮りで見つけた不具合を申し送りのメモで開発のセッションに渡しました。
- **夜に任せて、朝に確かめる**: 初日の夜、作り手が寝ている間に、雛形・データの取り込み・場面カード・指示・画面・評価までを作り、朝に作り手が確かめて方向を決めました（[docs/plan.md](docs/plan.md)）。
- **調査**: 国内外の受電 AI と、人を訓練する AI ロールプレイの事例調査をサブエージェントに任せ、報告を [docs/research/](docs/research/) に残しました。受付 AI が自分に課している規則（番号を1桁ずつ復唱、二段階の聞き返し）を、相手役の進め方と、人が使うカンペの言い方に借りています。
- **自分の目で確かめる**: Playwright と Chrome の開発者向けの仕組みで、9言語の画面がシステムの字体に落ちずに表示されることを確かめ、縦画面のデモ動画を撮りました。評価・相手役の確かめ・学習者役も Claude にした通しは、台本にして何度でも回せます（`scripts/`）。
- 毎日の出来事・つまずき・作り手の判断は [docs/journal.md](docs/journal.md) にあります。

## 配慮

- 医療の助言はしません。病院の場面でも、相手役は受付として名前・日時・用件を聞くだけです。
- 110番・119番など、安全や生命にかかわる場面は予行演習にしません。多言語の窓口を案内します。
- 「生活Can do」は「できるようにならなければならない一覧」ではありません。
- 会話の相手・店・地名・電話番号は、すべて架空です。練習で名乗る名前も架空で、画面の言語ごとに変わります。実在の人の録音や文字起こしは、リポジトリに入れません。
- カンペの QR は、推測できない URL で30日だけサーバーに置きます。
- 声の文字起こしが使えないときは、キーボード入力に切り替わります。
- ことばの説明は、国の用語集（やさしい日本語書き換え例、雇用管理に役立つ多言語用語集、法令用語日英標準対訳辞書）を先に使い、出典を出します。国の用語集に無い語（粗大ごみ・処理券・折り返し など295語）は Claude が書いた説明で、画面に「下書き」と出します（日本語教師が確かめる前。一覧は [docs/glossary.md](docs/glossary.md)）。訳も、厚生労働省の用語集の語は公式の訳、ほかは「訳: Claude」と出します。
- 公的な情報のリンクは、[yasashii-refs](https://github.com/silloi/yasashii-refs) の目録で確かめた国などのページだけです。Claude に URL を作らせません（場面ごとの対応は [docs/public-info.md](docs/public-info.md)）。

## データの出典と利用条件

- 文化審議会国語分科会「地域における日本語教育の在り方について」（報告）別冊「日本語教育の参照枠」に基づく「生活Can do」一覧（令和4年11月29日、文化庁 https://www.bunka.go.jp/seisaku/bunkashingikai/kokugo/hokoku/ ）を加工して作成。公共データ利用規約（PDL1.0）。jf の付いた Can do は国際交流基金の JF Can-do・JF生活日本語Can-do から採用されたもので、みんなのCan-doサイトの著作権ポリシーに従います。取り込みは [yasashii-refs](https://github.com/silloi/yasashii-refs) の `data/seikatsu-cando.jsonl` から（`scripts/build-data.ts`、詳細は `data/cando.meta.json`）。
- ふりがなは [Furifont](https://furifont.antfu.me)（Anthony Fu、0.7.0）を使っています。フォントは SIL Open Font License 1.1（Adobe の Source Han Sans から）、送りがなの続く漢字の読みを選ぶ表は CC BY-SA 4.0（JMdict・JMnedict・KANJIDIC2（EDRDG）、JmdictFurigana など）。読みを選ぶ処理は Furifont のユーザースクリプト（MIT）から移しました（`src/lib/furigana.ts`、ファイルと利用条件は `public/fonts/furifont/`）。
- 出入国在留管理庁・文化庁「在留支援のためのやさしい日本語ガイドライン 別冊 やさしい日本語書き換え例」（2020年8月 https://www.moj.go.jp/isa/support/portal/plainjapanese_guideline.html ）を加工して作成（PDL1.0）。画面の言葉をやさしい日本語に書き換えるときの用語集で、ことばの意味（用語集）にも使います（`data/plain-japanese.json`、`data/glossary/`）。
- 厚生労働省「雇用管理に役立つ多言語用語集」（2023年4月20日 https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/koyou_roudou/koyou/jigyounushi/tagengoyougosyu.html ）を加工して作成（PDL1.0）。ことばの意味と、10言語の訳に使います（中国語は简体・繁体の両方の公式の訳があります）。
- 日本法令外国語訳データベースシステム（法務省）「法令用語日英標準対訳辞書」第19.0版（https://www.japaneselawtranslation.go.jp/ja/dicts/download ）を加工して作成（PDL1.0）。場面と会話に出てくる語の英訳に使います。
- 用語集の取り込みは [yasashii-refs](https://github.com/silloi/yasashii-refs) の `data/` から（`scripts/build-glossary.ts`、出典と件数は `data/glossary/meta.json`）。公的な情報のリンクは、同じ yasashii-refs の目録（`catalog/`。各ページの発行元・URL・言語・確かめた日）から選んでいます（`scripts/build-public-info.ts`、`data/public-info.json`）。リンク先の内容は、それぞれの発行元の利用条件に従います。

| ---------- | ------------------------------------------------------------------------------------------------- |

学習者が話し終えてから相手の声が聞こえ始めるまで、およそ4.5〜5秒です（[docs/deploy.md](docs/deploy.md)）。仕様は [docs/spec.md](docs/spec.md)、場面の一覧は [docs/scenes.md](docs/scenes.md) です。

### ローカルで動かす

必要なもの: Node.js 22 以上、[Vite+](https://viteplus.dev/)（`npm i -g vite-plus`）

```bash
vp install
cp .dev.vars.example .dev.vars   # ANTHROPIC_API_KEY と ELEVENLABS_API_KEY を入れる
vp dev                           # root で動くコンテナでは CI=1 vp dev
```

```bash
vpx scripts/eval.ts --runs 2                    # 赤ペンの評価（ANTHROPIC_API_KEY が要る）
vpx scripts/check-dates.ts                      # 相手役が相対的な日を日付に直すか
vpx scripts/apply-gold.ts <書き出した JSON>     # /dev/gold で直した正解を入れる
vpx scripts/gold-sheet.ts > docs/eval-gold.md   # 正解を読みやすい形に
```

確認: `vp check`、`vp exec vue-tsc -b`、`vp test`
