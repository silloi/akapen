## 素材の動画（作り手に送ったもの。`local/`、git 管理外）

- `akapen-demo-draft.mp4`（2:44、11/5）: 最初の通し。学習者は英語話者の合成音声。住所が文字起こしで崩れ、相手役が聞き返す。
- `akapen-demo-v2.mp4`（4:21、11/6）: 相手役の会話の進め方（番号を1桁ずつ復唱、部屋番号を2回聞き返す）、赤ペン3つ、カンペ（書きとめる欄・QR）まで。学習者は日本語の合成音声。
- `akapen-demo-v3.mp4`（3:55、11/6）: 201 の読みを直し、学習者を英語話者の声（`eleven_v3`）に戻し、カンペを短くした版。
- `akapen-red-zh.mp4`（3:49、11/7、縦 1080×1920）: 中国の SNS（RED）に貼って、日本に住む中国語話者の反応を見るための版。スマホの縦画面・中国語の画面で、v3 と同じ会話と声を使い、操作の様子だけを淡々と映す（語りなし）。この会話では赤ペンは1つ（聞き返しができているので、残るのは「お金は？」のぶっきらぼうさだけ）。
- `akapen-red-zh-short.mp4`（1:31、11/7、縦 1080×1920）: 上の短い版。会話を4往復に絞り、赤ペンとカンペの生成を待つ時間は録画から抜いた（声の位置もその分ずらす）。名前が「JAWS 日语说得很好」になった後の画面。
- 縦画面の撮り方: Playwright の録画は CSS の大きさ（540×960）でしか撮れないので、Chrome の内部 API（`Page.captureScreenshot`、scale 2、clip はスクロール位置に合わせる）で 15 fps で撮り、ffmpeg で声と重ねる。声の位置は最初のフレームの時刻を 0 にそろえる（そろえないと画面が声より約4秒早く進む。11/7 に作り手が気づいた）（scratchpad の `video4/record2.cjs`・`mux2.cjs`）。
- 撮り方: `vp dev` を起動し、Playwright で画面を録画しながら、学習者の声（ElevenLabs の読み上げ）を本物の文字起こしにかけ、相手役の返事は前もって Claude から受け取ったものを順に出す。赤ペンとカンペは録画中にその場で Claude を呼ぶ。声は ffmpeg で重ねる。

## 導入の案（作り手のアイデア）

- 日本に溶け込んで暮らそうとしている外国人住民は、「日本語上手ですね」と言われるのを嫌がる。この一言を動画の最初のフックにする（例: 「日本語上手ですね」と言われない日のために。本番の電話を、本番の前に）。使うかどうかは作り手が決める。
