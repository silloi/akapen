# 評価の結果

作り手（日本語教師）の赤ペン（正解）と、Claude の赤ペンがどれだけ合うかを測る。会話は架空の8本（`eval/cases`、読みやすい形は `docs/eval-gold.md`）。

> **注意**: 今の正解は、Claude Code が作った**仮**のもの（`goldBy: draft`）。作り手が確かめて直したあとに、測り直す。8本と少ないので、数字は目安。

## 正解の確かめ方（作り手）

1. 公開先の https://jaws.ni-hongo.workers.dev/dev/gold を開く（このブラウザに自動で残る。サーバーには送らない）。
2. 会話ごとに、本番の前に直してほしい所に「赤」（多くても3つ、直す順）、直さなくていい所に「直さない」を入れる。横に、最新の評価で Claude が入れた赤が出るので、食い違う所の理由を「メモ」に書く。「決めてほしいこと」がある会話は、それに答える形で赤を入れる。
3. 確かめた会話に印を付け、「ファイルに書き出す」。ファイルをチャットに送る。
4. Claude Code が `vpx scripts/apply-gold.ts <ファイル>` で正解に入れ（引用が発話にそのまま無いなどの誤りがあれば止まる）、`vpx scripts/gold-sheet.ts > docs/eval-gold.md` と `vpx scripts/eval.ts --runs 2` を回して、この表と README を書き直す。

測り方（`eval/score.ts`）:

- **拾えた割合**: 正解の赤のうち、Claude も入れたもの（同じ発話で引用が重なれば合う）
- **合っていた割合**: Claude の赤のうち、正解にあるもの（低いと赤の入れすぎ）
- **種類の一致**: 合った赤のうち、種類（止まる・聞き取れない・失礼・文法）も同じもの
- **1番が合う**: 正解の1番と Claude の1番が同じ（正解に赤が無い会話は、Claude も入れなければ合う）
- **直さなくていい所への赤**: 正解で「直さなくていい」とした所（言いよどみ・伝わった文法の誤り）に入れた赤の数

### 2026-11-07.1（11/7）

「伝わったので、今は直さなくていいこと」（later）の上限を4つ → 6つにした（赤は3つのまま）。作り手が実際に使って「赤が少ない」と感じたが、仮の正解でも赤は1本あたり0〜3つで、3の上限に当たったのは1本だけ。少なく見えるのは、4つ目以降が later に入って折りたたまれていたからなので、画面では later を初めから開いて見せ、上限も広げた。赤ペンの見る順番・決まりは .2 のまま。

- 結果は .2 と同じ範囲（拾えた 67%・合っていた 86%・1番が合う 75%）。食い違いの中身も同じ（sodai-2 の「処理券」に「はい」、taxi-1 の「公園、あります。」）。
- later は1本あたり0〜4つで、6の上限には当たらなかった。上限を広げても、Claude が later を水増しすることはなかった。

### 2026-11-07.2（11/7）: 相手役に今日の日付とカレンダーを渡す

試し撮り（英語の画面）で、学習者の「来週の火曜日は、いいですか？」に、受付役が「来週の火曜日は、11月の何日でしょうか」と聞き返した。本物の受付は今日の日付を知っているので、聞き返さずに「来週の火曜日ですと、〇月〇日ですね」と日付に直して確かめる。相手役の指示に、今日の日付（日本時間）と8週ぶんのカレンダー（1行が月曜から日曜）を入れ、相対的な日は日付と曜日に直して復唱すること、過ぎた日は選ばないこと、こちらから出す日もカレンダーに合わせることを書いた（`shared/calendar.ts`）。赤ペンの指示は変えていない。

`vpx scripts/check-dates.ts`（相対的な日を言った所で止めた会話4つ × 今日を日曜日・火曜日の2通り × 2回）:

| 指示         | 日付に直した | 聞き返した | そのほか |
| ------------ | ------------ | ---------- | -------- |
| 2026-11-07.1 | 0 / 16       | 0          | 16       |
| 2026-11-07.2 | 16 / 16      | 0          | 0        |

- .1 では、相対的な日をそのまま繰り返すだけで、日付を一度も言わなかった（この回は「何日でしょうか」は出なかったが、日付を知らないので確かめようがない）。粗大ごみでは、場面カードの言い方の例「最短ですと11月18日の火曜日」を4回とも写した（2026年の11月18日は水曜日）。
- .2 では、16回とも正しい月日と曜日を言った（例: 日曜日に「来週の火曜日」→「11月10日ですね」、「来月の最初の土曜日」→「12月5日の土曜日ですね」）。日曜日の「来週」は月曜からの週と取った。違えば学習者が言い直せるように、月日をそえて確かめる。
- あわせて、場面カードの日付で実際の暦とぶつかるものを直した: 粗大ごみの言い方の例を「〇月〇日の〇曜日」に、下書きの場面の練習用の情報（「4月5日の土曜日」→「来週の土曜日」、「12月7日（土）」→「来月の最初の土曜日」、子どもの生年月日を月齢に合う年に など）と言い方の例2つ。
- 赤ペン: 拾えた・合っていた・1番は .1 と同じ。種類の一致が下がった（83% → 67%）のは2本の読み方の違い: taxi-1 の「わからない。」を、正解は「止まる」、Claude は「失礼」とした。taxi-2 は、正解が相手の「お迎えの場所」（聞き取れていない）、Claude は学習者のずれた答え「みなと駅です。」（止まる）に赤を入れた（同じつまずきとして合うとしている所）。どちらも作り手に決めてほしい所。

### .1 → .2 で直したこと

.1 では、学習者が**言わなかったこと**に赤を入れていた（「電話番号をまだ言っていません」「最後に日にちを確かめていません」を、終わりのあいさつに入れる）。正解に無い赤が多く、合っていた割合が 44% だった。

- 赤を入れるのは、実際に言ったことか、分からなかった相手の言葉だけにした。相手が聞かなかったことは、学習者の誤りではない。
- 「聞き取れていない」は、分かっていなかった証拠が会話にあるときだけにした（「はい」と答えただけで、話がずれていないなら入れない）。
- 1つのつまずきに赤は1つ。
- 「お金は？」「だめ」のような一語だけの言い方を、失礼の例に挙げた。

### 残っている食い違い（作り手に決めてほしいこと）

- **「はい」とだけ答えた難しい語**（sodai-2 の「処理券」、clinic-1 の「保険証」、sodai-1 の「家電リサイクル」）: 仮の正解では「聞き取れていない」として赤を入れたが、.2 の指示では「証拠が無ければ入れない」ので、Claude は入れない。**用件に欠かせない語なら、はいだけでも赤を入れるか**を、作り手が決める。拾えた割合が下がった（67% → 61%）のは、ほぼこれ。
- **taxi-1**: 正解は「わからない。」（話が止まった）だが、Claude は「公園、あります。」（目印があいまい）や「目印はありますか」（聞き取れていない）に入れることがある。
- **restaurant-2**（.1 のとき）: 「4人です。子どもが1人います。」を「大人4人＋子ども1人で5人と思われるかも」と赤にしたことがある。もっともな指摘なので、正解に入れるかを作り手が決める。

### effort

赤ペンは medium でも high と同じくらい合い、速い（8本を並べて約14秒）。アプリの赤ペンは medium、相手役は low、カンペは low にした。

## 通しの試し（学習者役も Claude）

`vpx scripts/simulate.ts <場面>` で、Claude に学習者役（つまずきやすい言い方をわざと入れる）をさせ、相手役と会話させてから赤ペンを入れた。結果は `eval/sim/`。

- 粗大ごみ: 相手役は冷蔵庫を受けられないことを伝え、「ゆっくり、もう一回」と頼まれると、短く区切って言い直した。赤ペンは「お金は？」の1つだけ。聞き返しや、用件の切り替え（いすだけ）に ○ を付けた。
- レストラン: 「コースは…いいです」に1番の赤（いる・いらないが分からない）、「駐車場は？」に2番の赤。最後の復唱で人数（大人3人と子ども1人）を言い足したことに ○。相手役は復唱して電話を終えた（ended）。
- 気づいたこと: 相手役は、場面カードに無い細かいこと（受付番号など）を自分で足すことがある。場面は架空なので害は少ないが、デモの前に見ておく。
