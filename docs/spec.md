# akapen 仕様（たたき台）

日本で暮らす外国人が、生活の場面（電話での予約、役所への問い合わせなど）を、本番の前に声で予行演習するアプリ。
学習用の会話相手ではなく、**本番を通すための予行演習とカンペ**として作る。

> 印（**未決**）の所は作り手が決める。

## 1. 流れ

1. 場面を選ぶ → 2. 予行演習（声） → 3. 赤ペン → 4. 本番のカンペ

## 2. 場面の選び方

- データ: yasashii-refs の `data/seikatsu-cando.jsonl`（kind が「生活Can do」785行、「生活・文化・社会的情報」145行）。
- 予行演習に使うのは、`activity` が「やり取り」の Can do のうち、相手と声で話すもの（電話か、窓口で向かい合って）。
- 場面カードは2種類ある:
  - **手書き**（`shared/scenes.ts`、4つ: 588 粗大ごみ・125 レストラン・160 タクシー・6 病院の受付）。作り手が確かめる。
  - **Claude の下書き**（`data/scenes.generated.json`、`scripts/build-scenes.ts`）。Claude が Can do の文と小分類の「生活・文化・社会的情報」を元に、手書きと同じ型で書く。別の呼び出しの検査役が、決まった項目（実在の名前・料金・電話番号が無いか、医療の助言が無いか、聞くことが Can do に合っているか、notes が一般的で断定しすぎていないか、安全の場面でないか、日本語が自然か）で見て、通らなければ指摘を付けて1回だけ書き直させる。通ったものを `status: "draft"` で入れる。
  - 画面では、先生が確かめた場面（`reviewed`）と下書き（`draft`、点線の枠と「下書き」の印）を分けて出す。作り手が確かめて直したら `reviewed` にする（読みやすい一覧は `docs/scenes.md`）。
- 電話の Can do（45）のうち、やり取りで安全にかかわらないもの20と、窓口（対面）の場面31を場面にした（11/6）。
- 安全や生命にかかわる場面（110番・119番、陣痛、医療相談など: 通番 4・46・51・72・216）は予行演習にしない。その場面を選ぼうとしたら、多言語の窓口・情報を案内する。
- 生活Can do は「できるようにならなければならない一覧」ではない、と画面に書く。
- 場面の名前と一言、画面の言葉は、やさしい日本語と第1群の9言語で出せる（まずやさしい日本語に書き換え、それを元に訳す。`scripts/build-i18n.ts`）。会話は日本語のまま。

## 3. 相手役（Claude）

- 場面ごとに、相手の役（受付・店員など）・聞くこと（名前・電話番号・日時・品目など）・本番で起きやすいこと（例: 冷蔵庫は粗大ごみで受けない）を「場面カード」として持つ。最初の場面は手で書く。Claude で下書きし、作り手が確かめる。
- ふるまい:
  - 本物の受付のように話す（敬語・決まった言い方を使う）。学習者に合わせて「やさしい日本語」にはしない。速さだけ、Can do の条件（「ゆっくりとはっきりと話されれば」）に合わせて選べる。
  - 会話の進め方は「本物の受付がだいたいこうする」という目安として書く（決まりで固めない）: 1回に1つ聞く、先に言われた情報は聞き返さない、ふつうの項目は次の質問に混ぜて復唱、名前・番号・日時・品目ははっきり復唱（番号は1桁ずつ）。
  - 通じないときは段階を踏む: 短く聞き返す → 理解の候補を出す・選べる形で聞く → 現実的な出口（担当に代わる・折り返す）。役所の場面（`office: true`）では、その前にやさしい日本語に切り替えてよい（多くの自治体が電話応対でしていること。店・タクシーでは切り替えない）。
  - 聞き返されたら、本物の受付がするように言い直す。
  - 相手の様子（ていねい・ふつう・急いでいる・気むずかしい）は、開始のたびにランダムに引く（本番の相手は選べない）。選ぶこともできる。難しさは学習者のレベルではなく相手役のふるまいとして決め、気むずかしい相手でも失礼な言葉は使わず、手順は守り、学習者が落ち着いて確かめれば話が進む。どの様子だったかは、赤ペンの画面で明かす。
  - 今日の日付（日本時間）とカレンダーを知っている。「来週の火曜日」のような相対的な日は、自分で日付に直し、月日と曜日をそえて確かめる。何日かを学習者に聞き返さない（11/7。`shared/calendar.ts`）。
  - 途中で日本語を教えない・直さない（赤ペンは後で別に入れる）。
  - 用件が終わる（または話が止まる）と終える。
  - 医療の助言はしない。病院の受付役は名前・日時・用件を聞くだけ。
- 練習で名乗る名前は、画面の言語ごとに差し替える（`shared/persona.ts`。本人・子ども・配偶者の3つ。場面カードには 〔名前〕〔子どもの名前〕〔配偶者の名前〕 と書き、画面と文字起こしの語（keyterms）で埋める）。どの言語でも同じ国の名前（グエン・ラン など）になっていたため（11/7、作り手の指摘）。住所・電話番号・日付は言語によらず共通。名前はすべて架空で、作り手が変えてよい。
- 予行演習の画面の横に「本番で聞かれること」を聞かれる順に出す（場面カードの `asks`。Can do の文に書かれた「伝えること」を、受付が聞く順に並べたもの。順番はカードを書いた側の判断）。横に練習用の架空の答えを添える。初級の人が「何を話せばいいか分からない」と言ったので足した（11/7）。見出しは9言語に訳す（`data/scenes.i18n.json` の `asks`）。聞かれることに付かなかった練習用の情報（生年月日など）の見出しも訳す（同 `info`）。日本語以外の画面では訳だけを見出しにし、答え（本番で言うこと）は日本語のまま。
- 会話の文には、ふりがなを付ける（Furifont。フォントが漢字の語に読みを付け、送りがなの続く漢字は表で読みを選ぶ。オン・オフを選べる）。文をタップすると、画面の言語で意味を出す（日本語・やさしい日本語の画面では、やさしい日本語に言い換える。`/api/translate` の `kind: "utterance"`、指示は `GLOSS_SYSTEM`）。作り手の提案（11/8）。
- 電話が終わったら、操作のボタン（話す・もう一度聞く・キーボード）を消し、その場所に大きい「赤ペンを見る」を出す。相手の最後の一言が流れている途中でも押せる（「もう一度聞く」の押しまちがいで、最後の一言を待ち直さないように。作り手の指摘、11/8）。「ここで終えて、赤ペンを見る」も、相手が話している間や聞き取りの間に押せる。話した後に「場面にもどる」を押すと、練習が消えることを確かめる。
- 相手が話し終えたら、自動で聞き取り（録音）に入る。電話と同じく、相手が話し終えたら自分の番なので。話し終えたら「話しおわった」を押す。キーボードで入力しているとき、相手の声が流れなかったとき、相手が電話を終えたときは入らない。聞き取り中に「もう一度聞く」を押すと、録った分を捨てて聞き直し、聞き終えたらまた聞き取りに入る。押し忘れに備えて、録音は60秒まで（11/7、作り手の提案）。
- 相手が話している間、マイクのボタンは「止めて話す」（押すと相手の声を止めて録音に入る）。マイクは、PC などでは練習の間ずっと開いておき、練習を出るときに閉じる（録音のたびに許可を聞かれないように）。iPad・iPhone では、録音のたびに開き、録り終えたらすぐ閉じる（マイクが開いている間は「通話」の扱いになり、相手の声が小さくなり、次の録音が空になったため。11/8）。
- 文字起こし: ElevenLabs Scribe。学習者の誤りと言いよどみを直さずに残す（確かめ: `docs/plan.md` の 1）。
- 相手役の声: ElevenLabs の読み上げ（第一候補）か、ブラウザの読み上げ。

## 4. 赤ペン

相手役とは別の呼び出しにする（Medkit に倣い、演じる役と、指針に照らして見る役を分ける）。

- 入力: 文字起こし（言いよどみつき）、場面カード、Can do の文。
- 見る順番（11/5 作り手が決めた）:
  1. 用件が変わる・止まる（例:「だいじょうぶです」が「はい」か「いいえ」か分からない）
  2. 相手の言葉を聞き取れていない（聞き返していない）
  3. 失礼・ぶっきらぼうに聞こえそう
  4. 文法・語の誤り（伝わったものは「今は直さなくていい」に入れる）
- 言いよどみ・言い直しは直さない。
- 本番までに直すことは、多くても3つに絞る。伝わった所には ○ を付ける。
- 出力（構造化出力）: 赤ペンごとに、種類・どの発話か（引用）・どこでつまずくか・次はどう言うか・優先順。
- 見せ方: 案A（添削）を土台にする（11/5 作り手が決めた）。3案は `docs/mock/akapen-views.html`。
  - 会話の記録に、そのまま赤を入れる。直す所は波線、聞き取れなかった相手の言葉は丸で囲み、行の下に手書き風の赤字で「どこでつまずく？ → 次はどう言う？」を書く。
  - 丸数字で直す順番を示す（多くても3つ）。伝わった所には ○ を付ける。
  - 案Cから2つ借りる: 赤ペンごとの「カンペに入れる」ボタンと、末尾の「伝わったので、今は直さなくていいこと」（多くても6つ。初めから開いて見せる。たたむと「赤が少ない」と見えるため、11/7）。赤が散らばって優先順が埋もれるという案Aの弱みを、これで抑える。

### もう一度練習する（2回目以降）

- 赤ペンを見た後、同じ場面をもう一度練習できる。予行演習の画面の横に、前回の赤ペンの「次はこう言う」を出す。
- 2回目の赤ペンでは、前回の赤ペンを Claude に渡し、同じつまずきが起きなかったかを ○（直せた）/ △（まだ）で返す。直せなかった所は今回の赤にも入れる。

## 5. 本番のカンペ

本番の電話や窓口で見る1枚のメモ。

- 聞かれること（相手の言い方と、その意味）
- 言うこと（自分の答え。赤ペンで直した言い方が入る）
- 困ったときの言い方（「番号をもう一度お願いします」「〜ということですか」のように、何を聞き返すかが分かる形を中心に）
- 言うことには、言ってもよい一言（「日本語を勉強中なので、ゆっくりお願いします」）、区切った電話番号、自分から確かめる言い方（「確認します。〜ですね」）を入れる。受付 AI が自分に課している復唱を、人間側の自衛の言い方として借りる
- 聞き取って書くこと（受付番号・日時・料金など）の空欄
- 前もって知っておくこと: その Can do の小分類 `minor_no` につながる「生活・文化・社会的情報」から選ぶ。例: 粗大ごみ（ごみの出し方）。
- その人の言語を並べる（**未決**: 最初に出す言語。例: 中国語・ベトナム語・英語・やさしい日本語）。
- 画面のほか、印刷できる。「スマホで開く（QR）」で、カンペをサーバー（Cloudflare KV）に推測できない ID で30日だけ置き、短い URL（`/k/<ID>`）の QR を出す。スマホで本番用の大きい文字の画面を開ける。URL を知っている人だけが開ける（Gyazo と同じ考え方。11/7 に、中身を URL に詰める形から変えた。QR が細かすぎて読めなかったため）。

## 6. 評価

MaestrIA に倣い、評価を先に作る。

- 架空の予行演習の文字起こしを用意する（場面ごとに数本。誤りの種類を変える）。作り手が赤ペンを入れる（正解）。
- Claude の赤ペンと比べる: 作り手が入れた所を Claude も入れたか（拾えた割合）、Claude だけが入れた所（入れすぎ）、上位3つの順番が合うか。
- 作り手が「直さなくていい」とした所に、Claude が赤を入れていないか（言いよどみ・伝わった文法の誤り）。
- 作り手は、正解を確かめる道具（公開先の `/dev/gold`）で、会話ごとに赤と「直さない」を入れ直し、判断の理由をメモに書く。最新の評価で Claude が入れた赤を横に出して、食い違いを見せる。サーバーには送らず、書き出した JSON を `scripts/apply-gold.ts` で `eval/cases` に入れる（11/7）。
- 相手役は、相対的な日（来週の火曜日）を日付に直して確かめるかを `scripts/check-dates.ts` で見る。
- 結果は docs/ に数字で書き、デモ動画でも見せる。
- 実在の人の録音・文字起こしは `local/`（git 管理外）でだけ使い、リポジトリには数字だけを書く。

## 7. 作り

- gyokan と同じ: Vite+ / Vue 3 / TypeScript / Cloudflare Workers。
- Worker: `/api/stt`（ElevenLabs Scribe へ）、`/api/tts`（相手役の声）、`/api/turn`（相手役）、`/api/akapen`（赤ペン）、`/api/kanpe`（カンペ）、`/api/scenes`・`/api/phone-candos`（場面）。
- Claude API: 構造化出力。モデルは gyokan と同じものから始める。
- キー: Claude は `ANTHROPIC_API_KEY`。ElevenLabs・Cloudflare は環境のネットワークシークレット。リポジトリに入れない。
