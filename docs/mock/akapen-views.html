赤ペンの見せ方 3案

同じ予行演習（粗大ごみの回収を電話で頼む。生活Can do 通番588・A2）を、3つの見せ方で並べました。どれも動きません。会話と人物は架空です。

3案とも共通: 言いよどみ（えっと・さん…さんちょうめ）は直しません。赤ペンは「伝わらなかった」「誤解されそう」を先に、文法の正しさは後にします。

案A

添削: 会話の記録に、そのまま赤を入れる

日本語教師が作文に入れる赤ペンに一番近い形です。会話の流れの中で、どこで止まったかが見えます。丸数字が直す順番です。

よい点

  • 「赤ペン」の名前とすぐ結び付く。デモで一目で分かる
  • 伝わった所に ○ を付けられる（ほめる赤ペン）

気になる点

  • 会話が長いと、赤が散らばって優先順が埋もれる
  • 「先生に直される」感じが強く、学習アプリに見えやすい
相手にはどう聞こえたか4往復
わたしが言った大きいごみを、捨てたいです。
受付に伝わった粗大ごみの申し込み
わたしが言ったれいぞうこ、と、いす。いすは…木の。
受付に伝わった冷蔵庫1台・木のいす1脚
受付が言った家電リサイクルの対象なので、お受けできないんです。
わたしが分かったこと？（「家電リサイクル」が分からない）
わたしが言っただいじょうぶです。
受付に伝わった冷蔵庫も出したい？ やめる？
→ 分からないので、もう一度聞かれる

赤い所: 2つ。ここで話が止まりました。

案B

相手の耳: 言ったことと、伝わったことを並べる

文法ではなく「伝わったか」だけで色を付けます。左が言ったこと、右が相手の受け取り方です。聞き取れなかった相手の言葉も同じ形で出せます。

よい点

  • 「正しさより伝わったか」という考えが、画面の形そのものになる
  • 学習用の会話相手との違いが、審査員に伝わりやすい

気になる点

  • 「相手にどう伝わったか」は Claude の推測。外れると信用を落とす
  • 直し方（次はこう言う）を置く場所が別に要る
本番の前に、直すのは2つ粗大ごみ・A2
1誤解されそう
「だいじょうぶです。」

「冷蔵庫は出さない」と「分かった」のどちらか、受付が決められません。何を出すかが決まらないと、申し込みが終わりません。

冷蔵庫はやめます。いすだけお願いします。

2聞き取れなかった
受付「家電リサイクルの対象なので…」

分からないまま進めると、冷蔵庫を出してしまい、回収されません。聞き返しは失礼ではありません。

すみません、「かでんリサイクル」は何ですか。

伝わったので、今は直さなくていいこと（3）
  • 「捨てたい、です」→ 伝わった。「粗大ごみ」と言えるともっと早い
  • 「いつ来ますか？」→ 伝わった。ていねいさも問題ない
  • 言いよどみ（えっと・さん…さんちょうめ）→ 電話ではふつう
案C

直すのは2つ: 優先順に絞り、カンペへ送る

本番までに直すことを、多くても3つに絞ります。順番に日本語教師の知見（用件が変わる誤りが先、言いよどみは直さない）を入れます。直したことは、そのまま本番のカンペに入ります。

よい点

  • 「本番を通す」目的に一番まっすぐ。練習 → 赤ペン → カンペが一続きになる
  • 作り手の赤ペンと Claude の赤ペンを「上位いくつが合うか」で比べやすい

気になる点

  • 会話のどこで起きたかが見えにくい（引用だけ）
  • 「赤ペン」らしさは案Aより弱い

決めてほしいこと

  1. どの案にするか（組み合わせもできます。例: 案Cを先に出し、「会話で見る」を押すと案Aの添削が開く）
  2. 優先順の決め方: 「用件が変わる・止まる誤り」＞「聞き取れない」＞「失礼に聞こえそう」＞「文法」の順でよいか
  3. 伝わった所に ○ を付けるか（ほめる赤ペン）

場面の出典: 文化審議会国語分科会「地域における日本語教育の在り方について」（報告）別冊「日本語教育の参照枠」に基づく「生活Can do」一覧（令和4年11月29日、文化庁）を加工して作成。会話・地名・人物は架空です。
