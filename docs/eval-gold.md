# 評価の会話と正解の赤ペン

`eval/cases/*.json` から作った読みやすい形（`vpx scripts/gold-sheet.ts > docs/eval-gold.md`）。会話はすべて架空。
正解の「誰が入れたか」が `draft` のものは、Claude Code が作った**仮**の正解で、作り手（日本語教師）が確かめて直す。直すときは JSON を直す。

## clinic-1（病院の予約を電話でする）

「だめ」がぶっきらぼう。「保険証」を聞き返さない

正解を入れた人: draft

0. 相手: はい、うみべ内科クリニックです。
1. **学習者**: あの、予約したいです。初めてです。
2. 相手: ご予約ですね。お名前と生年月日をお願いします。
3. **学習者**: チャン・ウェイです。1995年4月10日です。
4. 相手: 今日はどうされましたか。簡単で大丈夫です。
5. **学習者**: 3日前から、せきが出ます。
6. 相手: かしこまりました。明日の午前10時半でしたらお取りできますが、いかがですか。
7. **学習者**: だめ。仕事。
8. 相手: でしたら、明日の夕方5時はいかがでしょうか。
9. **学習者**: はい、5時、お願いします。
10. 相手: では明日の17時でお取りしました。当日は保険証かマイナンバーカードをお持ちください。
11. **学習者**: はい、わかりました。

| 順  | 種類             | 発話 | 引用         |
| --- | ---------------- | ---- | ------------ |
| 1   | 失礼に聞こえそう | 7    | だめ。仕事。 |
| 2   | 聞き取れていない | 10   | 保険証       |

直さなくていい所（赤を入れたら減点）:

- 1「あの」: 言いよどみ

## clinic-2（病院の予約を電話でする）

正解を入れた人: draft

3. **学習者**: はい、初めて。
4. 相手: お名前と生年月日をお願いします。
5. **学習者**: チャン・ウェイ、です。1995年、4月の10日。
6. 相手: ありがとうございます。今日はどうされましたか。
7. **学習者**: せきが、3日前から、出るでした。
8. 相手: かしこまりました。明日の午前10時半でしたらお取りできますが、いかがですか。
9. **学習者**: 10時半、いいです、お願いします。
10. 相手: では明日の10時半でお取りしました。保険証をお持ちください。
11. **学習者**: 保険証、持っていきます。ありがとうございます。

| 順  | 種類   | 発話 | 引用 |
| --- | ------ | ---- | ---- |
| -   | 赤なし | -    | -    |

直さなくていい所（赤を入れたら減点）:

- 1「したいでした」: 文法の誤りだが伝わった
- 7「出るでした」: 文法の誤りだが伝わった
- 9「いいです」: 「お願いします」が続き、意味が決まる

## sodai-1（粗大ごみの回収を電話で頼む）

0. 相手: お電話ありがとうございます。みなと市粗大ごみ受付センターです。
1. **学習者**: あの、えっと、ごみを、大きいごみを、捨てたい、です。
2. 相手: 粗大ごみの収集のお申し込みですね。お名前をフルネームでお願いします。
3. **学習者**: リン・メイです。
4. 相手: リン・メイ様ですね。ご住所をお願いします。
5. **学習者**: みなと市さくら町、さん、3丁目5の12、さくらハイツ201です。
6. 相手: ありがとうございます。何をお出しになりますか。
7. **学習者**: れいぞうこ、と、いす。いすは、木の。
8. 相手: 冷蔵庫は家電リサイクルの対象になりますので、こちらではお受けできないんです。
9. **学習者**: だいじょうぶです。
10. 相手: 申し訳ありません、冷蔵庫もお出しになりたいということでしょうか。
11. **学習者**: いすだけ。いつ来ますか？
12. 相手: いすだけですね。最短ですと11月18日の火曜日になりますが、よろしいですか。
13. **学習者**: はい。お金は？
14. 相手: 処理券を400円分、コンビニでお買い求めいただき、いすに貼って、当日の朝8時までにお出しください。
