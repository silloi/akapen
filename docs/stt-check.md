# 文字起こしの確かめ（合成音声で、仮）

実在の人の録音での確かめは後回しにした（`docs/plan.md`）。その前に、ElevenLabs の読み上げで「誤りと言いよどみを入れた日本語」を作り、Scribe で起こして、残るかを見た。読み上げは英語話者の声（Matilda）で日本語を読ませたので、少し非母語話者らしい発音になる。

- 日付: 2026-11-05
- 読み上げ: `eleven_multilingual_v2`（`language_code: ja`）
- 文字起こし: `scribe_v2`、`language_code: ja`、`no_verbatim: false`

| 読ませた文（誤り・言いよどみ入り）                    | Scribe の結果                                    | 見たこと                                                               |
| ----------------------------------------------------- | ------------------------------------------------ | ---------------------------------------------------------------------- |
| あの、えっと、ごみを、大きいごみを、捨てたい、です。  | あの、えっと、ゴミを、大きいゴミを捨てたいです。 | 言いよどみ（あの・えっと）と言い直しは残る                             |
| れいぞうこ、と、いす。いすは、えー、木の。            | 冷蔵庫と椅子。椅子はA、目の前。                  | 「えー」が「A」に、「木の」が「目の前」に。短い語の聞き違い            |
| わたしは、みなと町、さん、さんちょうめに、住むです。  | 私は湊路三三丁目に住むです。                     | 活用の誤り（住むです）は残る。地名は聞き違い                           |
| だいじょうぶです。                                    | 大丈夫です。                                     | そのまま                                                               |
| あした、来るますか？ 火曜日は、わたし、いないでした。 | 明日来ますか？火曜日は私いないでした。           | 「来るます」は**正しい形（来ます）に直された**。「いないでした」は残る |

## 分かったこと（仮）

- 言いよどみ・言い直しは、`no_verbatim: false` で残る。
- 文法の誤りは、残るもの（住むです、いないでした）と、正しい形に直されるもの（来るます → 来ます）がある。**Scribe の結果に誤りが無くても、学習者が誤らなかったとは言えない**。赤ペンは「文字起こしに残った誤り」しか見られない。
- 短い語・地名の聞き違いがある。赤ペンが、聞き違いを学習者の誤りとして赤を入れないようにする（相手役の受け答えと合わない所は「聞き取れなかったかもしれない」として扱う）。
- 合成音声なので、実際の学習者の発音・速さ・ためらいとは違う。実在の録音での確かめは、後でする。

## 通しの試しで分かったこと（2026-11-06、合成音声）

学習者の声（英語話者の声で日本語を読ませたもの）を Scribe にかけると、言いよどみは残ったが、**住所と電話番号が大きく崩れた**。

| 学習者が言ったこと                                          | Scribe の結果                                          |
| ----------------------------------------------------------- | ------------------------------------------------------ |
| えっと、みなと市さくら町3丁目5の12、さくらハイツの201です。 | えっと、港島桜町三丁目五の十二。桜はいつの日本一です。 |
| にっちゅう…？ あ、はい。090-1234-5678です。                 | 日中？あ、はい。09時、12時にいいです。                 |

- 相手役は、崩れた住所を受けて「建物の名前とお部屋の番号を、もう一度お願いできますか」と聞き返した（本物の受付らしい）。
- 赤ペンは、崩れた所（「桜はいつの日本一です。」）を「伝わらなかった」として1番の赤にし、「建物は、さくらハイツです。部屋は、にー、まる、いち。」と区切って言う言い方を出した。本番でも番号は聞き取りにくいので、的外れではない。ただ、原因が文字起こしの誤りか、発音かは区別できない。
- 数字（電話番号・部屋番号）は、Scribe の `keyterms` や、場面の練習用の情報を手がかりに渡すと良くなるかもしれない（未確認）。

## keyterms の効き目（2026-11-06、合成音声）

Scribe の `keyterms`（前もって渡す語。multipart では `keyterms` を繰り返す）に、場面の語と練習用の固有名詞（みなと市・さくら町・さくらハイツ・処理券・家電リサイクル）を渡して比べた。

| 声                   | keyterms | 結果（「さくらハイツの201」の所）  |
| -------------------- | -------- | ---------------------------------- |
| 英語話者の声で日本語 | なし     | 桜はいつの日本一です               |
| 英語話者の声で日本語 | あり     | さくらハイツの二号一です           |
| 日本語の声           | なし     | 桜ハイツの二ゼロ一です             |
| 日本語の声           | あり     | さくらハイツの二〇一です（正しい） |

- 固有名詞には効く。Worker の `/api/stt` は、場面カードの `keyterms` を渡すようにした（料金は 20% 増）。
- 電話番号「090-1234-5678」は、日本語の声なら「零九零一二三四五六七八」と正しく起こせる（英語話者の声では崩れたので、発音の問題）。1つずつ読んだ漢数字は、算用数字に直して画面に出す（`shared/numbers.ts`）。

## 読み上げの数字の読み（2026-11-06）

作り手が動画で、「201号室」が「ニセンイチ」「ニジュウイチ」と読まれるのに気づいた（ふつうは「ニーゼロイチ」）。文字起こしでは「二ゼロ一」としか戻らないので、読みの誤りは文字起こしでは見つけられない。読み上げに渡す前に、部屋番号・受付番号・電話番号を1桁ずつカタカナにする（`shared/reading.ts`）。日付・金額・数量はそのまま。
