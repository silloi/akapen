# 作品の概要（下書き）

作り手が直す。作り手の経歴などは、作り手に聞いてから書く。

## 名前

JAWS 日本語じょうず（英語表記: JAWS: Nihongo Jozu。リポジトリ名は akapen）

## 一言で

生活の電話を、本番の前に声で予行演習する。伝わらなかった所に日本語教師の赤ペンを入れ、本番で手元に置くカンペを作る。

## 課題

日本で暮らす外国人にとって、電話での予約や問い合わせ（粗大ごみの申し込み、お店・タクシー・病院の予約）は、顔が見えず、聞き返しにくく、一度きりの本番です。実際に、病院の予約の電話をかける前に、生成 AI を相手に練習していた人がいました。けれど、ふつうの AI の会話相手は、分かりにくい答えでも都合よく汲み取って先に進み、どこで本番の相手が困るかを教えてくれません。

## 何をするか

1. 文化庁の「生活Can do」から場面を選ぶ（電話と窓口、50場面。4つは日本語教師が手で書き、46は Claude が下書きして別の検査役が確かめた。先生が確かめるまで「下書き」と表示）。
2. Claude が本物の受付として話す相手役になり、声でやり取りする。日本語を教えたり直したりせず、あいまいな答えには本物のように聞き返す。本番で起きやすいこと（例: 冷蔵庫は粗大ごみで出せない）が1つ入る。
3. 会話の記録に赤ペンを入れる。文法の正しさより「伝わったか」を先に見る。優先順は「用件が変わる・止まる ＞ 聞き取れていない ＞ 失礼に聞こえそう ＞ 文法」。直すのは多くても3つ。言いよどみは直さない。
4. 本番のカンペを、その人の言語と並べて作る。赤ペンで直した言い方が入り、その場面で前もって知っておくこと（生活・文化・社会的情報）を添える。

## Claude の使い方

- 相手役と赤ペンを別の呼び出しにした（演じる役と、指針に照らして見る役を分ける）。
- 赤ペン・カンペは構造化出力で受け取り、引用が会話に文字どおりあるかを確かめてから画面に出す。
- カンペの「知っておくこと」は、渡した情報だけから書かせ、料金や制度などの事実を足させない。
- 評価: 日本語教師が入れた赤ペンと Claude の赤ペンの一致（拾えた割合・入れすぎ・1番が合う割合・直さなくていい所への赤）を測り、指示を直した。
- 場面の広げ方: Claude が場面カードを下書きし、別の呼び出しの検査役が決まった項目（実在の名前・数字、医療の助言、Can do との対応、知っておくことの一般性）で見て、通らなければ書き直させる。人が最後に確かめる。モデルが良くなれば、場面も赤ペンも良くなる構造。

## 配慮

- 医療の助言はしない。病院の場面でも、相手役は受付として名前・日時・用件を聞くだけ。
- 110番・119番など、安全や生命にかかわる場面は予行演習にせず、多言語の窓口を案内する。
- 「生活Can do」は「できるようにならなければならない一覧」ではない、と画面に書く。
- 会話の相手・店・地名・電話番号はすべて架空。練習では架空の名前や電話番号を使える。

## 使ったもの

Claude API（claude-opus-5-5）、ElevenLabs（Scribe・読み上げ）、Vue 3、Cloudflare Workers。データは文化審議会国語分科会「生活Can do」一覧（文化庁、PDL1.0）を加工して作成。
